# BUSI 444: Advanced Computer Assisted Mass Appraisal - Case Study Examination

## Project Overview
This repository contains the work completed for the BUSI 444 Case Study Examination. The primary goal of this project was to develop an Advanced Multi Regression Analysis for Mass Appraising. 


## Key Objectives & Requirements
* Develop a direct sales comparison-based approach model (additive multiple linear regression)
* Review and select appropriate variables from the database, including transformations.
* Calibrate the model
* Completely test and evaluate both models from appraisal and assessment perspectives. 
* Provide conclusions on model quality and recommend the most effective model to the Assessor.
* Recommend any necessary actions for the Assessor before using the model. 
* Meet IAAO's minimum requirements (CODs < 15% and median ASRs between 90% and 110%).

## Location for Mass Appraisal 
* **Location:** Mid-sized city in Northern Ontario.
* **Population (2016 Census):** 70,563.
* **Real Estate:** Approximately 24,000 dwelling units, 70% owned, 30% rented. Single detached homes make up 65% of housing stock. Sales data is from the densely developed urban core.
## Database
* The database contains 466 sales records and 57 variables spanning the period from March to October 2017

## Methodology
The project involved:
1.  **Data Preparation:** Reviewing variables, performing necessary transformations. [cite: 65, 71]
2.  **Direct Sales Comparison Model Development:**
    * Defining the general additive multiple linear regression model.
    * Variable selection using various analytic techniques.
    * Model calibration using multiple linear regression.
4.  **Model Testing & Evaluation:** Both models were thoroughly tested for appraisal level, dispersion (compared to IAAO standards), horizontal equity, and vertical equity.
5.  **Reporting:** An appraisal report was prepared following the "Mass Appraisal Report Outline" provided in the examination details.
